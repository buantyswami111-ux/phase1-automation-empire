# Power Automate Desktop Flows

This directory stores exported Power Automate Desktop flows for the PC Federation.

## How to Export Flows

1. Open Power Automate Desktop
2. Right-click on your flow
3. Select "Export" → "Export flow"
4. Save the `.txt` file to this directory
5. Commit to GitHub for version control

## How to Import Flows

1. Open Power Automate Desktop
2. Click "Import" in the toolbar
3. Select the exported `.txt` file from this directory
4. The flow will be imported and ready to run

## Naming Convention

Use descriptive names for your exported flows:
- `empire-{function}-{version}.txt`
- Example: `empire-backup-logs-v1.txt`

## Example Flows

Create flows for tasks like:
- Automated file backups
- Scheduled data exports
- Desktop notification systems
- Integration with Tab A9 logs
